# Euclas：從這份文件開始

Euclas 的重點是「組織」，不是只讓 AI 寫程式。你先與一位持續存在的助理做事，逐漸建立家庭、公司、個人工作或俱樂部；也能邀請真人加入。

數位人的身分、責任、記憶與工作留在 Euclas，底下的 Codex、Claude Code、模型與工具可以替換。切換不能讓權限擴大、來源遺失或正在執行的工作偷偷換版本。工程上要把變動隔離在接入層，但不能保證任何上游更新都完全不用調整。

## 你會看到的產品

- 桌面應用：先 macOS 與 Windows，未來 Linux；一般使用者不必安裝 Docker 或操作 Terminal。
- 原生手機 App：iOS／Android；安全配對到開著、醒著且就緒的那台主機。手機不另啟一套助理，也不因主機離線把工作移到雲端。
- 每一層的助理都可直接互動，可以命名、置頂。主管處理例行品質與記憶問題，真的超出權責才向上詢問。
- 首頁呈現需要你判斷的事與可讀成果。工作圖可拖曳、聚合、點選個別數位人；組織圖另外表達正式責任與層級。首版以可用的2D為主。
- 文件、聊天、報告與成果旁回覆共享同一工作及版本；聊天不取代正式工作紀錄。
- 你可以和 AI 做自己的儀表板與 Plugin，在桌面、手機共同使用。個人、公司、部門各有自己的版本，不必放上市集。

## 第一個要證明的成果

以老闆準備客戶提案為例：桌面登入→助理理解有範圍的需求→實際執行→產生可編輯文件與可讀版本→主管先審例行問題→老闆判斷價格、承諾與不確定資訊→正式確認→重開仍可讀回同一份成果。

這是第一個完整驗證切片，不是把完整首版縮成只有文件產生器。真人協作、手機、Plugin、Windows、兩種 harness 目標與長工作更新連續性仍保留。

## 三個重要邊界

1. 手動關閉桌面應用就停止本機執行；只有經授權、已驗證的更新交接可保留相同執行控制器。更新不能為了逾時而強殺長工作。
2. 官方 Euclas 帳號用 Email 驗證碼登入，帳號不等於組織權限。已驗證裝置遇斷網最多沿用24小時既有本地授權；本機撤權即刻生效。保守初版在重新開機或無法可信計算休眠時間時需連線驗證。
3. 完整開源優先；沒有已定案的助理數或組織深度付費限制。雲端代管、確切授權與收入方案尚未定案，不自動開啟額外 API 費用。

## 現在的起點

這個目錄只有整理後的現行設計、介面規則、驗收與開發方法。舊程式、Git歷史、過期設計與舊完成紀錄沒有帶入。所有產品功能與 runtime 驗收從未實作／未執行開始。

「契約」指工程上的介面與行為規格：誰可以做什麼、要交回哪些資料、成功／拒絕／重複／失敗時怎麼處理。它是重新實作的共同依據，不是法律合約或既有程式。
