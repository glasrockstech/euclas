# Source-boundary and complete containment qualification

Q2 owns OpenShell-first qualification against this matrix and GR-SEC-003/006; R04/R12 recheck each release tuple. These are requirements, not executed probes. CPU-only boundary tests can isolate deterministic containment before a model/GPU/provider is added, but they do not close complete useful-work/G2 qualification.

Each authorized probe declares owned disposable source/output paths, actual native filesystem/mount identity, process/credential/network/resource limits and descendant ownership. It needs no secret, real business data or unknown host-service access. Runtime installation/process/network probes require their explicit scope; this file authorizes none.

| Attempt | Required refusal or safe behavior |
|---|---|
| Source read-only, writable workdir/ancestor alias | Effective policy remains read-only, including implicit baseline permissions; failed/unknown path identity blocks admission |
| Symlink, traversal, mount/root replacement | Canonical path is insufficient alone; trusted native root/file/mount/type/ownership identity must match at use/publish |
| Read unrelated workspace/other Unit/host config | No unauthorized bytes, summaries, existence leaks or inherited broad mounts |
| Access controller/admin socket or credentials | No containment-engine/DB/migration/native controller authority exposed to workload or renderer |
| Bypass action gateway using shell/network | Filesystem/network/credentials enforce actual boundary; prompt refusals, endpoint lists and backend config acceptance are not proof |
| Revoke network with an established connection | Current policy applies to active connections/descendants as qualified; unsupported enforceability refuses the capability |
| Spawn detached/child process and exit parent | Ownership and stop/revoke reach all relevant descendants; no orphan authorized effect |
| Exceed CPU/memory/disk/process/time envelope | Enforce bounded profile, visible stop/failure and uncertain effects, not host denial of service or silent limit expansion |
| Tool/model returns forged producer/pass/approval | Typed validation and trusted issuer provenance reject it; no new rights from UUID/method/output confidence |
| Stop/cancel/revoke then delayed callback | Fenced epoch/current authority prevents resurrection; uncertain external effect reconciles with original key |
| Useful real content/coding/tool workflow | Actual permitted work completes inside the same restrictions with correct sources/bytes/evidence; a toy refusal-only demo is insufficient |

OpenShell is conditionally selected only after all four conditions pass on the same declared tuple: installation/maintenance feasibility, complete useful work, effective isolation and stop/revoke/recover. If it fails, evaluate an alternative against the same tests and retain failures/limits; no brand-only hard dependency or weaker substitute.
