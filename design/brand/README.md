# Euclas 品牌與介面準則

現行品牌是 B1 標誌、墨色／柔白／礦石藍及 “Your organization, crystal clear.”。主品牌 Euclas；產品 Euclas OS、Euclas App、Euclas Cloud；公司署名 by Glasrocks。OS 指應用平台，不是替換主機作業系統。

只包含現行向量母版及 token 資料，不含產品介面、HTML demo、產生器或過往檢查紀錄。比例、字級、斷點是設計預設；不代表每個數值都經使用者個別確認或已通過實機驗收。

## 標誌

![B1 橫式標誌](assets/horizontal-charcoal.svg)

母版：[symbol-black.svg](assets/symbol-black.svg)。`assets/` 有橫式黑／墨／白、直式黑／白、獨立符號與淺／深／礦石藍 App 圖示，共用同一幾何，不重新描圖。字標已轉為路徑；不以介面字體重打代替，不拉伸、旋轉、換其中一段顏色、加描邊／光暈／陰影。

標誌四周至少保留符號高度1/4。獨立符號24px、橫式140px寬起作檢視預設；16px與實際平台圖示需另驗證。App 母圖1024×1024，符號約占60%，平台圓角由容器／正式輸出規則處理。商標近似、素材權利及平台發布仍須正式查核。

## 色彩與 tokens

[tokens.json](tokens.json) 是共用色彩、尺寸與動態資料來源。未包含 CSS 或元件實作；之後由它產生產品適用的 token exports，避免散寫色碼。

| 品牌 | 色碼 | 用途 |
|---|---|---|
| Ink | #18212D | 文字與中性圖形 |
| Soft White | #F6F7F9 | 淺色背景 |
| Mineral Blue | #315ED4 | 主要操作、連結、焦點與品牌強調 |

深色操作使用 #9CB8FF，搭配 #101419 深色文字；品牌礦石藍保留在適當品牌表面。不要直接將淺色按鈕搬入深色背景。一般工作畫面保持中性色、節制強調；5–10%彩色面積只是構圖參考。

淺／深主題的 surface、text、muted、border、controlBorder、accent/hover/onAccent/soft、success/warning/danger/info 都在 JSON 中。必要控制邊界用 controlBorder，分隔線 border 不能獨自充當控制線索。狀態同時有文字／圖形；執行成功不等於成果已驗收，未知不可畫成零或綠色就緒。

## 字體與排版

使用平台系統字體與可用繁中文字體，不自動下載後備字體。正文16px，桌面控制14px，輔助12px，區段20px，頁面28px（手機可24px）；正文行高繁中約1.7、西文1.55。代碼／路徑／版本才用等寬字。預留翻譯150%文字增長，不縮字塞德文；Logo 字體不是內文字體。

4px 基準間距，常用4/8/12/16/24/32/48。桌面邊距24–32px、手機16–20px；控制／容器／對話框圓角8/12/16px。用對齊、留白與細分隔建立秩序，避免卡片套卡片、裝飾性霓虹或玻璃材質。

## 工作與手機介面

先決策、再進展、後設定；首頁沒有注意事項時誠實呈現。結果先可讀，再讓人深入來源、版本與限制。範圍持續可見，切換組織不偷偷送出草稿。停止後區分已停止與仍待核對，不使用沒有可信總量的百分比。

桌面可用側欄／詳情區；手機採單欄與完整閱讀頁，返回保留位置／草稿。相同工作、來源、值、單位、警告及版本在各裝置一致；完整表格可達，橫向捲動限表格內。不靠下載 PDF 才能閱讀，不讓固定按鈕遮住重要內容。

設計起始斷點為768／1200px；以360/390/768/1280px、200%縮放、三種語言與鍵盤測試，不把斷點當原生裝置支援證據。桌面控制視覺高度約36–40px，觸控有效區至少44×44。選取同時用標記／字重／語意，不能只靠顏色。

## 無障礙與回饋

一般文字對比4.5:1、大字3:1、必要非文字操作／狀態線索3:1；焦點2px accent外框與2px間距。標籤持續可見，錯誤在欄位附近且可修正。表格／圖有標題、單位、期間、來源／限制與可達資料替代。所有主要流程可鍵盤操作，動態尊重 reduced motion。

回饋動態120–180ms、面板180–240ms是預設，不做持續呼吸光。讀者向上閱讀不自動捲到底，新增內容提供提示。離線／快取內容標示過時或唯讀，失敗有恢復入口。

Token 對比或 SVG 有效不等於整體無障礙、平台圖示或產品驗收已通過。改符號或主色需新的產品決定；一般可逆版面細節依現行需求調整並驗證。
